# Farmers Market Price and Sales Tracker

A console-based Java project that records produce prices, quantities, three-day sales, remaining stock, and revenue for a farmers market.

## Project Overview

This academic project demonstrates fundamental Java programming through a practical market-sales application. It organizes produce data, calculates total sales and remaining stock, determines revenue, and identifies the highest-earning product.

## Java Concepts Used

- Data types: `String`, `int`, `double`, `boolean`, and `char`
- Arithmetic, comparison, assignment, and increment operators
- Conditional statements: `if`, `else if`, and `else`
- Loops: `for`, `while`, and `do while`
- Static methods
- One-dimensional and two-dimensional arrays
- No explicit object creation and no `this` keyword

## Features

- Displays a three-day sales table
- Calculates product-wise sales totals
- Calculates remaining stock and revenue
- Classifies price and stock levels
- Finds the highest-earning product
- Displays a final market summary

## Repository Structure

- `FarmersMarketTracker.java` — complete Java source code
- `output/` — sample program output screenshots

```bash
javac FarmersMarketTracker.java
java FarmersMarketTracker
```
